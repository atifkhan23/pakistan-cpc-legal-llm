# Data

The dataset files are **not included** in this repository yet.

- **Source text:** *Code of Civil Procedure 1908: Commentary* by Amir Raza A. Khan and Ibrahim Haroon (19th edition, Commercial Law Publishers, Lahore). This book is copyrighted, so neither the book nor the extracted corpus text is distributed here.
- **QA dataset (CPC-PKL):** 2,467 question-answer pairs generated by an LLM from the extracted text. Before release, it is being reviewed for close paraphrases of the source and for case citations that do not appear in the source (about 24% of citation mentions, see `../results/citation_audit/`).

To run the code, place the dataset file here (or point `DATA_PATH` to it):

```
data/final_legal_dataset.json     # JSON list of {"instruction", "input", "output", "type"}
```

`src/split_data.py` then creates `data/train.jsonl`, `data/val.jsonl` and `data/test.jsonl` (stratified 80/10/10, seed 42).

For access to the dataset for research purposes, contact the author.
